## Mod Loaders

MiniMash is currently being developed for Fabric. Support for NeoForge will be added when version 1.0.0 for Fabric has been released.

## Backports

MiniMash is currently in development for Minecraft 26.3.
We plan on backporting this mod to 1.21.1 once the version 1.0.0 for 26.3 has been released for Fabric and NeoForge.

There are currently no plans to backport to versions before Minecraft 1.21.1.
